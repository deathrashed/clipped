## Key Decisions
- Pixelation uses `backdrop-filter: blur()` for visual block effect — works in Chrome/Puppeteer headless which Remotion uses.
- FerroFluid uses SVG `<ellipse>` primitives with `feGaussianBlur` — no Three.js dependency, works in all Remotion rendering modes.
- Strobe uses `useCurrentFrame()` — cannot be used in simpler renderers without frame hooks. Tier: disabled prevents rendering through ElementStack unless explicitly overridden.
