## What needs to be built next — Netlify Functions for YouTube clipping

This is the main unfinished feature. Riley confirmed: Netlify Functions (server-side) are the right approach for yt-dlp, not browser-only.

### Architecture

```
Browser → POST /.netlify/functions/clip-request
          body: { url, start, end, format }
        ← { jobId: "abc123" }

Browser polls every 2s:
  GET /.netlify/functions/clip-status?job=abc123
  ← { status: "pending"|"done"|"error", error?: "..." }

Background function (triggered by clip-request):
  /.netlify/functions/clip-job-background
  1. yt-dlp → /tmp/{jobId}.%(ext)s
  2. ffmpeg trim + fade → /tmp/{jobId}_clip.mp3
  3. Read file, store in Netlify Blobs under key jobId
  4. Set status blob to "done"

Browser, on done:
  GET /.netlify/functions/clip-download?job=abc123
  ← streams blob as audio/mpeg with Content-Disposition: attachment
```

### Key constraints

- **Background functions** needed (not sync) — yt-dlp + ffmpeg takes 10–60s depending on video length/quality. Background functions have 15 min timeout, sync have 30s.
- **256 KB response limit on background functions** — can't return audio in the response body. Must store in Netlify Blobs and serve via a separate download function.
- **Netlify Blobs** — available on all plans (including Free). Use `@netlify/blobs` npm package. Keys are arbitrary strings, TTL can be set. Store the audio file under `jobId` and a status string under `jobId:status`.
- **Binary bundling** — yt-dlp and ffmpeg static Linux x86_64 binaries must be committed to the repo (or downloaded in a build plugin). Netlify functions run on Amazon Linux 2 x86_64. Both binaries must be `chmod +x`.

### Binary sourcing

**yt-dlp:**
```bash
curl -L https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp \
  -o netlify/functions/bin/yt-dlp
chmod +x netlify/functions/bin/yt-dlp
```
Size: ~15 MB. Commit to repo. Add to `.gitignore` exemption if needed.

**ffmpeg (slim audio-only static build):**
Use the yt-dlp/FFmpeg-Builds release — Linux x86_64, `ffmpeg-master-latest-linux64-gpl.tar.xz`.
Extract only the `ffmpeg` binary (~70 MB uncompressed, ~25 MB compressed).
Or use `ffmpeg-release-amd64-static.tar.xz` from johnvansickle.com (more reliable, audio codecs only build is ~8 MB).

Committed path: `netlify/functions/bin/ffmpeg`

**Both binaries:** add to `.gitignore` negation or just commit directly. They're one-time downloads.

#### `netlify/functions/clip-request.js`

Sync function. Validates input (URL must be a YouTube/SoundCloud URL, start/end are numbers, format is mp3/wav). Generates a `jobId` (uuid or `Date.now().toString(36)`). Stores `{url, start, end, format, jobId}` as a pending job in Netlify Blobs (`jobId:status` = `"pending"`). Returns `{ jobId }`. Also triggers the background function — in Netlify, you do this by calling `fetch('/.netlify/functions/clip-job-background', { method: 'POST', body: JSON.stringify({jobId}) })` without awaiting it (fire and forget), or by using the background function naming convention and calling it directly.

Actually the cleaner pattern: make `clip-request` itself a background function that does everything. Then the frontend just polls a status endpoint that reads from Blobs. clip-request-background receives the URL, runs the job, writes to Blobs.

Simplest flow:

```
POST /.netlify/functions/clip-request-background
  body: { url, start, end, format }
→ 202 immediately + { jobId } in response body...

Wait — background functions return 202 with empty body by design.
```

The 202 doesn't carry a body back to the client reliably. Better pattern:

1. **clip-request** (sync, fast): generate jobId, write `jobId:status=pending` to Blobs, then `fetch` the background function URL async (fire-and-forget, don't await). Return `{ jobId }` to browser.
2. **clip-job-background** (background): reads job params from Blobs, runs yt-dlp + ffmpeg, writes result + status.
3. **clip-status** (sync): reads `jobId:status` from Blobs, returns it.
4. **clip-download** (sync): reads audio blob by jobId, streams it.

#### `netlify/functions/clip-request.js`

```js
import { getStore } from '@netlify/blobs';
import { randomUUID } from 'crypto';

export const handler = async (event) => {
  if (event.httpMethod !== 'POST') return { statusCode: 405 };
  const { url, start, end, format } = JSON.parse(event.body || '{}');

  // Basic validation
  if (!url || !url.match(/youtube\.com|youtu\.be|soundcloud\.com/)) {
    return { statusCode: 400, body: JSON.stringify({ error: 'Invalid URL' }) };
  }

  const jobId = randomUUID();
  const store = getStore('clip-jobs');
  await store.set(`${jobId}:params`, JSON.stringify({ url, start, end, format }));
  await store.set(`${jobId}:status`, 'pending');

  // Fire background function (no await)
  const bgUrl = `${process.env.URL}/.netlify/functions/clip-job-background`;
  fetch(bgUrl, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ jobId }),
  }).catch(() => {});

  return {
    statusCode: 200,
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ jobId }),
  };
};
```

#### `netlify/functions/clip-job-background.js`

```js
import { getStore } from '@netlify/blobs';
import { execFile } from 'child_process';
import { promisify } from 'util';
import { readFile, unlink } from 'fs/promises';
import path from 'path';

const exec = promisify(execFile);
const BIN = path.join(process.cwd(), 'netlify/functions/bin');
const YTDLP = path.join(BIN, 'yt-dlp');
const FFMPEG = path.join(BIN, 'ffmpeg');

export const handler = async (event) => {
  const { jobId } = JSON.parse(event.body || '{}');
  if (!jobId) return { statusCode: 400 };

  const store = getStore('clip-jobs');

  try {
    const params = JSON.parse(await store.get(`${jobId}:params`, { type: 'text' }));
    const { url, start, end, format } = params;

    const tmpRaw = `/tmp/${jobId}_raw`;
    const tmpClip = `/tmp/${jobId}_clip.mp3`;

    // Download audio
    await exec(YTDLP, [
      '-x', '--audio-format', 'mp3',
      '--audio-quality', '0',
      '--ffmpeg-location', FFMPEG,
      '--no-playlist',
      '-o', tmpRaw + '.%(ext)s',
      url,
    ]);

    const rawFile = `${tmpRaw}.mp3`;

    // Trim + fade
    const ffmpegArgs = ['-i', rawFile, '-ss', String(start || 0)];
    if (end) ffmpegArgs.push('-to', String(end));
    ffmpegArgs.push(
      '-af', 'afade=t=in:d=0.3,afade=t=out:st=' + Math.max(0, (end||60) - start - 0.3) + ':d=0.3',
      '-c:a', 'libmp3lame', '-q:a', '2',
      tmpClip, '-y'
    );
    await exec(FFMPEG, ffmpegArgs);

    const audioData = await readFile(tmpClip);
    await store.set(`${jobId}:audio`, audioData, { metadata: { contentType: 'audio/mpeg' } });
    await store.set(`${jobId}:status`, 'done');

    // Cleanup
    await Promise.allSettled([unlink(rawFile), unlink(tmpClip)]);
  } catch (err) {
    await store.set(`${jobId}:status`, 'error:' + err.message.slice(0, 200));
  }

  return { statusCode: 200 };
};
```

export const handler = async (event) => {

#### `netlify/functions/clip-download.js`

```js
import { getStore } from '@netlify/blobs';

export const handler = async (event) => {
  const jobId = event.queryStringParameters?.job;
  if (!jobId) return { statusCode: 400 };
  const store = getStore('clip-jobs');
  const blob = await store.get(`${jobId}:audio`, { type: 'arrayBuffer' });
  if (!blob) return { statusCode: 404, body: 'Not found' };
  return {
    statusCode: 200,
    headers: {
      'Content-Type': 'audio/mpeg',
      'Content-Disposition': `attachment; filename="clip-${jobId.slice(0,8)}.mp3"`,
    },
    body: Buffer.from(blob).toString('base64'),
    isBase64Encoded: true,
  };
};
```
