How to Install and Setup CLI Wrapper globally? ▼

Global CLI Installation

Clipped can be set up globally by running the install script in the repository. Make sure the output path is added to your shell profile path (e.g. .zshrc):

  • cd ~/Scripts/Riley/clipped
  • ./install.sh
  • export PATH="$PATH:$HOME/Scripts/Riley/clipped/bin"
  • Check connection: clipped --help
Common Rendering and Audio Trimming Troubleshooting ▼

Fixing Render Faults

  • Symptom: clipped command not found.
    Solution: Run ./install.sh and confirm the binary path is matched in your profile configuration.
  • Symptom: Remotion renders fail instantly before starting frame pipeline.
    Solution: Navigate to src/remotion, clean out package logs, and run a fresh installation:
    cd src/remotion && rm -rf node_modules package-lock.json && npm install
  • Symptom: Video renders have missing or default icons and covers.
    Solution: Make sure you render from a full-length, tagged track inside the original directory containing the image assets, rather than from a pre-flattened clip.
  • Symptom: Output reels are truncated to exactly 60 seconds.
    Solution: Specify --platform vertical_full to bypass the Instagram/TikTok duration limits.
